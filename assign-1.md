What happens between typing a URL and seeing the page?

When we type a URL in a web browser and press Enter, several steps take place to load and display the webpage. 
1. Entering the URL : User enters a website address, such as www.google.com, into the browser and presses Enter. 
2. DNS : DNS (Domain Name System) converts the domain name into an IP address. 
3. Establishing a Connection : The browser establishes a secure connection with the server. 
4. Sending an HTTP Request : The browser sends an HTTP request to the server to access the requested webpage. 
5. Server Response : The server processes the request and sends the required files, such as HTML, CSS, JavaScript, and images, back to the browser. 
6. Rendering the Webpage : The browser processes HTML to create the structure, CSS to apply styling, and JavaScript to add functionality. 
7. Displaying the Page : Finally, the browser renders the webpage and displays it on the screen, allowing the user to interact with it.
